# 這是什麼

本來源檔疑似為金融機構市場風險衡量或控管規範的條文摘錄，可辨識內容包括「99%」及「Portfolio VaR（投資組合風險價值）」等字樣。由於大部分文字仍為亂碼，無法可靠確認法規全名、條次、發布機關、生效日期及完整計算要求。

> 使用提醒：本頁僅整理來源中可辨識的風險管理概念。不得據此認定特定 VaR 參數、限額或申報義務；實際作業應回查可讀版本的原始規範、主管機關函令及本行內部制度。

# 跟我們業務的關聯

來源內容顯示該規範可能要求以 VaR 衡量投資組合風險，並可辨識到「99%」的數值，但其具體用途及其他參數無法完整還原。對固定收益／債券交易部門可能影響如下：

- **投資組合風險衡量**：債券、利率商品及相關衍生品部位可能須納入 Portfolio VaR 計算，以整體投資組合層級衡量市場價格變動可能造成的損失。
- **信賴水準設定**：來源可辨識到「99%」，可能是 VaR 的信賴水準要求；但持有期間、歷史觀察期間、資料頻率及計算方法均無法確認，不宜僅依本頁設定模型參數。
- **交易限額與風險監控**：VaR 結果可能被用於內部限額、預警、超限通報、部位調整或升級審批。交易人員應同時留意名目額度、久期、DV01、信用利差及集中度等其他限制，不能只看 VaR。
- **模型與計算流程**：若 VaR 用於法定資本計提或正式風險限額，通常會牽動市場資料品質、部位涵蓋範圍、風險因子對應、模型變更、獨立驗證及計算紀錄留存。
- **回溯測試與異常處理**：實際損益若多次超過模型預估損失，可能代表模型低估風險，需要調整模型、提高資本或採取其他控管措施；但本來源是否明定回溯測試及其門檻，尚無法確認。
- **風險治理與報告**：相關結果可能須定期提供風險管理單位、高階管理層或內部委員會，並就超限、模型例外及重大市場波動提出說明。
- **固定收益風險補充指標**：債券部位具有利率、信用利差、選擇權及流動性風險。即使符合 VaR 限額，也應搭配壓力測試、情境分析、久期、凸性、DV01／PV01、信用集中度及流動性指標判斷風險。

由於法規身分與條文內容無法辨識，本頁不能用來確認：

- 哪些機構或交易簿部位適用；
- 是否屬法定資本計提、內部管理或其他用途；
- VaR 的持有期間、觀察期間、計算頻率及模型方法；
- 是否存在特定乘數、回溯測試門檻、壓力 VaR 或申報期限；
- 超限後應採取的法定處置及核准層級。

# 關鍵定義

- **VaR（Value at Risk，風險價值）**  
  用統計方法估計：在指定持有期間及信賴水準下，投資組合因市場價格變動可能承受的損失範圍。VaR 是機率估計，不代表損失絕不會超過該數值。

- **Portfolio VaR（投資組合風險價值）**  
  將多項持倉及其價格連動關係一併納入計算的 VaR。它會考慮不同部位間的分散或抵銷效果，不等於把每一商品的個別 VaR 直接相加。

- **99% 信賴水準**  
  若採 99% 信賴水準，白話來說，模型預期約有 99% 的觀察期間損失不超過 VaR，仍可能約有 1% 的情況超過。其實際意義必須搭配持有期間及模型假設判讀。

- **持有期間（Holding Period）**  
  VaR 所估計的風險期間，例如一天或十天。持有期間越長，估計風險通常越高；本來源無法確認要求採用的期間。

- **回溯測試（Backtesting）**  
  將模型預估的 VaR 與實際或假設損益比較，檢查模型是否經常低估風險。損失超過 VaR 的情形通常稱為例外或突破。

- **壓力測試（Stress Testing）**  
  模擬利率急升、殖利率曲線扭轉、信用利差擴大或市場流動性惡化等極端情境。壓力測試可補充 VaR 對極端事件及尾端風險掌握不足的問題。

- **模型風險**  
  因模型假設、歷史資料、風險因子、估值方法或程式錯誤，使計算結果低估或錯估實際風險的可能性。
