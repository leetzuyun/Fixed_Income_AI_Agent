# 這是什麼

本準則是永豐金證券「銷售交易部」依公司「債券業務管理辦法」訂定的內部規範，適用於與非專業機構投資人從事固定收益證券交易時的業務執行及風險管理。

內容涵蓋適用市場與客戶資格、債券信用評等、買賣斷及附條件交易、附賣回維持率與額度、結構型商品銷售，以及利害關係人與利益衝突管理。

# 跟我們業務的關聯

本準則直接影響固定收益／債券交易部門的客戶准入、標的篩選、定價、交易文件、額度占用及交易後監控，重點如下。

## 適用市場與客戶准入

- **適用市場（第2條）**：限於證券商得以自營方式交易的 **DSU及OSU市場**。承作前應確認交易帳簿、市場及作業流程是否落在本準則範圍內。
- **適用客戶（第3條）**：以非專業機構投資人為交易對象，主要包括：
  - 專業客戶之自然人
  - 專業客戶之法人
  - 高資產客戶
  - 高淨值投資法人
- **資格審查（第3條）**：業務人員應依客戶類別確認財力、金融商品知識、交易經驗、風險承擔能力及申請文件，並完成認識客戶作業。不能只憑客戶自稱具備資格。
- **高齡客戶（第4條）**：高齡客戶以自行買賣方式進行債券交易時，除一般法規外，還要依金融交易事業處另訂的高齡客戶管理措施辦理。

主要客戶資格門檻如下：

| 客戶類別 | 主要門檻 |
|---|---|
| 專業客戶之自然人 | 財力證明達新臺幣3,000萬元以上，並具備充分的金融商品知識及交易經驗 |
| 專業客戶之法人—從事衍生性金融商品交易 | 最近一期經會計師查核或核閱的財務報告總資產超過新臺幣1億元 |
| 專業客戶之法人—不從事衍生性金融商品交易 | 最近一期財務報告總資產超過新臺幣5,000萬元；境外法人財報得免經會計師查核或核閱 |
| 高資產客戶 | 可投資資產淨值及保險商品價值達新臺幣1億元以上；或於本公司的可投資資產淨值達3,000萬元以上，並另提出持有1億元以上可投資資產及保險商品價值的聲明 |
| 高淨值投資法人 | 淨資產超過新臺幣200億元、設有投資專責單位、持有有價證券部位或衍生性金融商品投資組合達新臺幣10億元以上，且具備適當投資程序及風險管理措施 |

## 債券信用評等的認定

- **多家信評不一致（第5條）**：原則上採各核准信評機構最新發表的評等；若同時發表，採最低評等。僅列入觀察名單、尚未正式調整的資訊不納入評等判斷。
- **三家信評中一家調降（第5條）**：若其中一家最新評等降至不符合客戶承作規定，可自公布日起設一個月觀察期。若期間內沒有第二家也調降至不符規定，銷售交易部應完成風險評估、會簽風險管理處，並經金融交易事業處處長同意，才可在市價評估及不增加附賣回餘額的前提下，採次佳評等辦理展期。
- **外部評等優先（第6條）**：發行人有外部信用評等時，優先使用外部評等；沒有外部評等時，才以內部信用評等作為參照。
- **主順位債券（第6條）**：
  1. 有債券本身評等時，使用債券評等。
  2. 無債券評等但有金融機構擔保時，使用擔保機構評等。
  3. 無債券評等且無擔保時，使用發行公司評等。
  4. 發行公司也無評等時，視為無評等。
- **次順位債券（第6條）**：原則上應使用債券本身或擔保機構評等；無債券評等且無擔保時視為無評等。但本國金融控股公司及本國金融機構發行的次順位債券，無債券評等時，可用發行機構評等的次一級。
- **聯合擔保債券（第6條）**：無債券本身評等時，以各擔保機構中最低的評等為準。
- **投資等級（第6條）**：指 Moody’s Baa3、S&P BBB-以上（含），或其他主管機關認可的相當等級。

## 買賣斷交易

- **最低信用評等（第7條）**：在營業處所與適用客戶自行買賣國內、外債券時，除中華民國政府公債外，債券至少應符合下列門檻：

| 信評機構 | 最低評等 |
|---|---:|
| Fitch | BB |
| Moody’s | Ba2 |
| S&P | BB |
| 中華信評 | tw BBB |
| 惠譽台灣 | BBB(twn) |

- **高資產及高淨值客戶例外（第8條）**：與高淨值投資法人及高資產客戶自行買賣外國債券時，不受「證券商受託買賣外國有價證券管理規則」第6條第1項的外國債券信用評等限制；但其他內部風險控管仍應遵守。
- **專業投資人限定國際債（第9條）**：僅限銷售予專業投資人的國際債券，交易對象也必須是專業投資人，且應明確告知買方日後只能再賣給專業投資人。
- **海外關係企業來源揭露（第10條）**：銷售給國內投資人的外國債券若取自海外關係企業，應告知投資人其取得來源。

## 附條件交易文件、期間與結算

- **交易文件（第11條、第12條）**：承作前除應簽訂債券附條件買賣總契約書及附約，也要一併簽訂增補契約書等相關文件。
- **不得相抵結算（第13條）**：除與金融機構交易外，不得對同一客戶將債券買賣斷與附條件交易，或買斷與賣斷交易，相互抵銷後辦理給付結算。
- **交易期間（第14條）**：
  - 一般附條件交易：不得超過一年。
  - 依總契約附約承作的中央登錄公債附條件交易：不得超過一個月。
  - 外幣債券附賣回（RS）：不得超過三個月，並依修正式次營業日慣例處理。

## 價差與利率

- **買賣斷價差（第15條）**：單筆交易價差以年化費率 **0.5%** 為上限。
- **附賣回利率（第15條）**：可按牌告利率或議價承作。議價時，以交易員詢得的附賣回利率或貨幣市場資金成本為基礎，再考量信用評等、流動性、天期及幣別，按幣別加計：
  - 台幣：0.10%～2.00%
  - 外幣：0.25%～2.00%
- **附買回利率（第15條）**：可按牌告利率或議價承作。

## 附賣回維持率、客戶限額與集中度

- **標準維持率（第16條）**：
  - 台幣債券：115%
  - 外幣債券：130%
- **客戶承作總限額（第17條）**：

| 客戶類別 | 附賣回交易承作限額 |
|---|---:|
| 專業客戶之自然人或法人 | 等值美金300萬元 |
| 高資產客戶 | 等值美金800萬元 |
| 高淨值投資法人 | 等值美金1,000萬元 |

客戶需求超過上述限額時，須由客戶提出申請，經金融交易事業處處長同意並副知風險管理處後，才能承作。

- **同一法人及關係企業集中度（第17條、附件一）**：法人客戶另按金控評等設定RS交易對手額度上限，以永豐金證券淨值的一定比例計算：

| 金控評等 | RS交易對手額度上限 |
|---|---:|
| H1～H4 | 淨值25% |
| H5～H6 | 淨值10% |
| H7～H9 | 淨值1% |

實際控管應依風險管理處最新公告內容辦理。

- **單一債券總額上限（第17條）**：金融交易管理部應依標的信用評等控管單一債券的附賣回承作總額，上限如下：

| 大致國際信評區間 | 單一債券上限（等值美元） |
|---|---:|
| AA-／Aa3／AA-以上 | 90,000,000 |
| A+～A-／A1～A3 | 70,000,000 |
| BBB+～BBB／Baa1～Baa2 | 50,000,000 |
| BBB-／Baa3 | 25,000,000 |
| BB+～BB／Ba1～Ba2 | 10,000,000 |
| BB-／Ba3 | 5,000,000 |

本國評等應依第17條表列的中華信評及惠譽台灣對應級距判斷。

## 各客戶類別的標的折扣與承作額度

- **專業客戶及高資產客戶（第18條、附件二）**：單一標的承作金額按債券市值乘以對應比例計算。外幣債券主要級距如下：

| 國際信評 | 專業客戶 | 高資產客戶 |
|---|---:|---:|
| A-／A3以上 | 市值80% | 市值80% |
| BBB～BBB+／Baa2～Baa1 | 市值75% | 市值75% |
| BBB-／Baa3 | 市值70% | 市值70% |
| BB+／Ba1 | 市值65% | 市值65% |
| BB／Ba2 | 市值55% | 市值55% |
| BB-／Ba3 | 不適用 | 市值50% |

台幣債券依中華信評或惠譽台灣評等計算：

| 本國信評 | 專業客戶 | 高資產客戶 |
|---|---:|---:|
| tw AA-／AA-(twn)以上 | 市值85% | 市值85% |
| tw A～tw A+／A(twn)～A+(twn) | 市值80% | 市值80% |
| tw A-／A-(twn) | 市值75% | 市值75% |
| tw BBB～tw BBB+／BBB(twn)～BBB+(twn) | 市值70% | 市值70% |
| tw BBB-／BBB-(twn) | 不適用 | 市值60% |

- **高淨值投資法人（第19條、附件三）**：不受一般維持率限制，但仍須依標的評等套用承作比例：

| 信評區間 | 附賣回交易額度 |
|---|---:|
| AA-／Aa3／AA-以上，或本國最高評等區間 | 標的債券市值95% |
| A-～A+／A3～A1 | 標的債券市值93% |
| BBB-～BBB+／Baa3～Baa1 | 標的債券市值90% |
| BB-～BB+／Ba3～Ba1 | 標的債券市值75% |

- **評等變動（第20條）**：評等一旦變化，應立即依最新評等重新套用額度上限及客戶類別規則。
- **承作金額基準（第21條）**：可使用當日債券市場含息價（Dirty Price）或與交易對手議定的市價作為參考市價，再乘以評等對應比例計算承作上限。
- **低於最低評等（第22條）**：不得作為新增附賣回交易的標的；但若債券託管於永豐金證券OSU，可納入客戶擔保維持率的資產項目評估。
- **公司保留承作權（第23條）**：即使債券符合最低評等，公司仍可依風險判斷決定不承作。

## 維持率監控與追繳

金融交易管理部應每日監控客戶附賣回額度、標的市價及市值維持率（第24條）。

| 產品 | 通知補足門檻 | 提前到期門檻 |
|---|---:|---:|
| 台幣債券 | 低於115% | 低於105% |
| 外幣債券 | 低於130% | 低於110% |

- 低於通知補足門檻時，金融交易管理部應通知銷售交易部業務人員，再由業務人員通知客戶並留存紀錄；客戶應於 **10個營業日內**補足現金或擔保品。
- 低於提前到期門檻時，公司應通知客戶附賣回交易提前到期，並依契約處理債券擔保品。
- 如因市況或特殊情形要使用不同維持率，須以專案方式會辦風險管理處及金融交易管理部，經總經理核准並副知稽核處。
- 高淨值投資法人若簽署 **GMRA**，按交易對手方式進行風險管理；若簽署一般附條件買賣總契約書，則依上述維持率機制辦理。

## 信評調降後的展期

客戶在附賣回期間遇到標的評等降至不符內部承作規定，且到期無法結清時，應提出原因及自行簽署的還款計畫，經有權主管核准並副知風險管理處後，才可展期（第25條）。

展期標的最低信評不得低於：

- S&P：B+
- Moody’s：B1
- Fitch：B+
- 中華信評：tw BB+
- 惠譽台灣：BB+(twn)

單筆展期核決權限如下：

| 核決主管 | 單筆核決額度上限（等值美元） |
|---|---:|
| 金融交易事業處處長 | 500,000 |
| 金融交易事業處督導 | 1,000,000 |
| 總經理 | 1,500,000 |

## 結構型商品銷售與揭露

- **交易文件（第26條）**：應簽訂衍生性金融商品總約定書或ISDA主契約，並提供產品說明書、客戶須知、風險預告書及交易確認書；英文文件應提供中文譯本。
- **適合度與風險揭露（第26條）**：應依公司商品適合度、風險告知、揭露及交易紛爭處理制度辦理。
- **行銷過程留痕（第27條）**：應宣讀或以電子設備說明重要內容，並以錄音或電子軌跡留存；對專業客戶可用書面或影音媒體交付取代。
- **自然人客戶（第27條）**：應由專人解說；不保本商品的解說過程須錄音或錄影，契約並應約定同意主管機關及櫃檯買賣中心蒐集、處理及利用個人資料。
- **不保本商品（第27條）**：應取得客戶「未受勸誘以借款或舉債取得交易資金」的聲明，並留存紀錄。
- **專業客戶提示（第27條）**：應告知專業客戶不受金融消費者保護法保障。
- **客戶屬性覆核（第27條）**：客戶屬性評估及分級應由適當單位或人員覆核，至少每年檢視一次並取得客戶確認。
- **職務分離（第27條）**：辦理客戶屬性評估的人員不得與銷售結構型商品的人員相同；自然人首次屬性評估還須錄音、錄影或留存電子作業軌跡。

## 利益衝突、利害關係人及公平待客

- **一般銷售義務（第28條）**：業務人員應遵守善良管理人注意義務、忠實義務及公平待客原則，充分揭露投資風險，不得鼓勵客戶以借款或舉債投資。
- **CSDR延遲交割罰款（第28條）**：公司若依歐盟證券交割及集保法收受交易對手支付的延遲交割罰款，應依公平合理原則給付受影響客戶。
- **交易前查核（第29條）**：自營交易前應查詢交易對象是否為利害關係人或公司受僱人員。
- **與利害關係人或受僱人員交易（第29條）**：
  - 買賣斷單筆價差仍以年化0.5%為限。
  - 同日同標的有不同成交價格時，應留存足以證明條件未優於同類對象的紀錄，例如委託時間。
  - 附買回原則上依牌告利率承作，且不得優於同類對象。
  - 附賣回原則上依牌告利率承作；無相對應天期或幣別牌告利率時，依第15條議價規範辦理，且不得優於同類對象。
- **禁止交易對象（第30條）**：不得與總經理、金融交易事業處督導、金融交易事業處所屬員工及其配偶從事債券買賣斷或附條件交易。
- **附條件交易不得優於同類對象（第31條）**：適用於董事、經理人、持股10%以上股東及其配偶、未成年子女、借名持有人、符合條件的轉投資公司，以及公司受僱人員。
- **洗錢防制與訓練（第32條）**：業務人員應了解利害關係人及利益衝突規範，遵守洗錢防制要求並定期接受金融商品訓練。

## 例外與法規更新

- **未規定事項（第33條）**：須取得金融交易事業處處長核准並副知風險管理處後，才能承作。
- **法令先行（第34條）**：外部法令已更新但本準則尚未完成修訂時，應先依最新法令及公司其他相關規定辦理。
- **核定層級（第35條）**：本準則及其修正均由總經理核定後施行；本次修正於2025年8月18日核定。

# 關鍵定義

- **DSU／OSU市場（第2條）**：本準則指定的自營交易適用市場。實際承作時應依公司對DSU及OSU的帳務、託管與作業規範判斷。
- **專業客戶（第3條）**：符合規定財力、知識及交易經驗，主動向公司申請，並了解成為專業客戶後部分保護或公司責任可能被免除的自然人或法人。
- **高資產客戶（第3條）**：符合較高資產門檻，並經公司確認具備金融商品知識、交易經驗及充分風險承擔能力的自然人或法人。
- **高淨值投資法人（第3條）**：具有高額淨資產及投資部位，並設有專責投資單位、專業人員、投資程序及風險管理措施的法人。
- **外部信用評等（第6條）**：中華信評或主管機關核准、認可的信用評等機構所評定的信用等級。
- **內部信用評等（第6條）**：依公司「信用風險管理辦法」與金控內部評等轉換的等級，共分為1至9及D；1代表信用品質最佳，D代表違約。1至4為低度風險、5至6為中度風險、7至9為高度風險，原則上1至6為可投資等級。
- **投資等級（第6條）**：Moody’s Baa3、S&P BBB-以上（含），或主管機關認可的相當評等。
- **買賣斷**：債券所有權直接移轉、不另約定將來買回或賣回的交易。
- **附賣回交易（RS）**：客戶先買入債券，並約定未來由公司買回的交易；對客戶而言通常具有短期資金運用性質。
- **附買回交易**：客戶先賣出債券，並約定未來買回的交易。
- **附賣回交易維持率（第16條）**：以「債券總資產市值 ÷ 附賣回交易金額」計算，用來衡量擔保資產是否足以支應交易曝險。
- **Dirty Price／含息價（第21條）**：包含應計利息的債券價格，可作為計算附賣回承作上限的當日參考市價。
- **展期（第5條、第25條）**：附賣回到期後延長交易期限。若涉及信評調降或無法結清，必須符合最低信評、還款計畫及核決權限要求。
- **GMRA**：Global Master Repurchase Agreement，全球附買回交易主契約。高淨值投資法人簽署GMRA時，其附賣回風險管理按交易對手方式辦理。
- **集中度限額**：為避免曝險過度集中於同一法人及其關係企業，按交易對手評等及公司淨值比例設定的最高額度。
