# 這是什麼

本準則要求本公司針對自營單位在非集中交易市場承作的外幣計價債券（含可轉債）及衍生性金融商品，建立成交價格與市場價格或模型公平價值的合理性檢核程序。風險管理處負責每日檢核，並在市場狀況重大變動時檢視現行標準是否仍然有效。

# 跟我們業務的關聯

這份準則直接影響固定收益／債券交易部門在 OTC（非集中交易市場）場景的日常作業，重點如下：

- **適用產品與交易範圍**
  - 本公司自營單位承作的外幣計價債券，包含可轉債。
  - 本公司自營單位承作的衍生性金融商品。
  - 附件所列外幣債券、IRS 及 NDIRS，均以 Bloomberg 作為交易資料及市場資料來源，並檢核內部單與外部單。

- **交易當日須進行價格合理性檢核**
  - 檢核當日所承作金融商品的成交價格與市場價格之差異是否合理。
  - 確認時點為 `TradeDate = "Today"`。
  - 價格差異標準依附件「金融商品成交價格合理性檢核標準表」辦理。

- **外幣債券的市場價格取價方式**
  - 交易資料來源及市場資料來源均為 Bloomberg。
  - 依「永豐金證券市場風險管理辦法」所定取價邏輯，以 Bloomberg 下午 4:30 的日終價格為基準。
  - 有 BGN 時優先使用 BGN；無 BGN 時使用 BVAL；再無 BVAL 時，依公司規定的取價順序依序取價。

- **外幣債券的價格差異標準**
  1. **當沖交易**：以當日買進及賣出成交價相互比較，價格差異比率原則上不得超過 2.5%。
  2. **當日買進交易**：以買進成交價與當日市場價格比較，計算公式為：  
     `（成交價－市場價格）／市場價格`  
     價格差異比率原則上不得超過 2.5%。
  3. **當日賣出交易**：以賣出成交價與前一日市場價格比較，計算公式為：  
     `（成交價－前日市場價格）／前日市場價格`
  4. 買進與賣出交易須分開檢核並計算比例，作為價格差異合理性的判斷依據。

- **特定上手報價債券可適用較寬的門檻**
  - 債券清單須先由交易單位提交風險管理處審查通過。
  - 價格差異比率原則上不得超過 8%。
  - 該債券須同時符合下列條件：
    - 發行量小於 300M。
    - 價格來源為 BVAL。
    - 僅限於特定帳戶交易。

- **IRS／NDIRS 的檢核標準**
  - 交易資料及市場資料來源均為 Bloomberg。
  - 確認時點為 `TradeDate = "Today"`，檢核內部單與外部單。
  - 檢核公式採絕對值：  
    `|(MarketValue + UpfrontFee) / DV01|`
  - IRS：計算結果須小於 2.99。
  - NDIRS：計算結果須小於 5.06。

- **偏離標準時，交易員須在期限內說明**
  - 風險管理處每日執行價格合理性檢核。
  - 發現交易偏離價格差異標準時，風險管理處應通知交易員、交易單位主管及風險管理處主管。
  - 交易員須於二日內以 email 回覆差異原因，回報風險管理處，並副知交易單位主管備查。

- **上手提供報價入帳的衍生性商品另有規範**
  - 衍生性金融商品若採上手提供報價入帳，其價格合理性檢核標準及流程，依「衍生性金融商品採完全拋補方式交易之評價及控管機制辦理細則」辦理。
  - 交易及入帳作業應先確認所承作商品是否屬於此類情形，以免使用錯誤的檢核標準。

- **檢核標準可能因市場或業務變化而調整**
  - 市況發生重大變動時，風險管理處應檢視價格差異標準是否仍然有效。
  - 本準則至少每年依實際業務需求或法令變動檢視是否需要修訂。
  - 準則修正原則上由總經理核定；附件「金融商品成交價格合理性檢核標準表」的修訂，則授權風險管理處處長核定。因此實際作業時應確認使用的是最新附件版本。

# 關鍵定義

- **非集中交易市場**：未透過集中交易市場撮合的交易場景，通常也稱為 OTC 市場。本準則針對自營單位在此類市場承作的指定金融商品建立價格檢核要求。
- **市場價格（Market Price）**：用來與實際成交價格比較的基準價格。外幣債券依公司市場風險管理規範，以 Bloomberg 下午 4:30 日終價格及既定的 BGN、BVAL 取價順序取得。
- **公平價值（Fair Value）**：無適當市場價格或依產品特性採模型評價時，由模型計算出的價值，可作為成交價格合理性檢核基準。
- **BGN**：Bloomberg Generic Price，由 Bloomberg 綜合市場報價形成的參考價格；依本準則附件，外幣債券有 BGN 時優先採用。
- **BVAL**：Bloomberg Valuation Service 提供的評價價格；外幣債券無 BGN 時使用，也是特定上手報價債券須符合的價格來源條件之一。
- **內部單／外部單**：附件要求納入價格檢核的交易類型；不論交易被歸類為內部單或外部單，均在所列產品的確認交易範圍內。
- **確認時點（TradeDate = "Today"）**：表示以交易日為當日的交易資料進行檢核。
- **當沖交易**：同一交易日內買進及賣出同一標的的交易；本準則以當日買進與賣出成交價相互比較。
- **特定上手報價之債券**：經交易單位提交清單並由風險管理處審查通過，且符合發行量小於 300M、價格來源為 BVAL及僅限特定帳戶交易等條件的債券；其價格差異門檻原則上可放寬至 8%。
- **IRS**：利率交換（Interest Rate Swap），本準則以 `|(MarketValue + UpfrontFee) / DV01| < 2.99` 作為合理性標準。
- **NDIRS**：無本金交割利率交換（Non-Deliverable Interest Rate Swap），本準則以 `|(MarketValue + UpfrontFee) / DV01| < 5.06` 作為合理性標準。
- **DV01**：利率變動一個基點時，金融商品價值預估變動的金額，用來衡量利率風險敏感度；在 IRS／NDIRS 檢核公式中作為分母。
- **MarketValue**：IRS／NDIRS 依市場條件評估的交易價值，為價格合理性公式的計算項目之一。
- **UpfrontFee**：交易開始時支付或收取的前端費用；本準則要求與 MarketValue 合併後，再除以 DV01 進行檢核。
