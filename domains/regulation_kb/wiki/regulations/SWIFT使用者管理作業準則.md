# 這是什麼
本準則是永豐金證券為管理公司內部使用 SWIFT（環球銀行財務電信協會）系統之人員權限與安全控管而訂定的內部作業規範，重點涵蓋「誰能做什麼」、「如何申請/變更權限」、「Token 與密碼如何保管/更新」以及相關文件保存。

# 跟我們業務的關聯
固定收益／債券交易部門雖然不一定直接操作 SWIFT 電文，但在實務上常會涉及結算、通匯與跨行訊息的發送/接收流程；本準則會影響你們的日常作業方式，主要關聯如下：

- **權限分工與不得兼任**：要求管理單位、作業單位角色獨立運作、使用者功能權限依部門/業務特性申請且不可兼任，避免交易訊息放行或修改等關鍵步驟由同一人同時控制，間接影響你們在交易/結算流程中可能對應到的 SWIFT 作業環節（如電文放行或修改）。
- **電文處理功能的授權範圍**：將權限分為 *Message Creation、Message Modification、Message Approval、Message Search & Report、RMA*。若固定收益/債券相關作業人員需要查詢報表或參與特定電文流程，必須符合相對應功能授權。
- **權限新增/變更的申請流程**：使用人員新增或變更功能，須填寫申請書與人事審查表，經單位主管覆核後由管理者設定授權；這會影響你們在業務調整、角色異動時，如何提出 SWIFT 權限需求。
- **Token 領取、盤點與移轉控管**：管理者設定完成後需通知領取 Token，並登記於 Token 移轉控管登記表、執行每半年盤點；若你們涉及 Token 領取/歸還或角色變更，需依此流程操作。
- **密碼規則與定期更新**：規範密碼長度（6–10 字元）、需混用特定字元類型（至少 3 種來源類型），並要求保密且半年定期更新；此將影響任何需要使用 SWIFT 系統帳密的作業人員行為準則。
- **文件歸檔保存 5 年**：每日進、出電文相關文件，以及憑證申請相關文件需歸檔留存，保存期限 5 年。若交易/結算流程涉及你們產出或需提供的電文文件，會影響你們如何確保資料可追溯。

# 關鍵定義
- **SWIFT 系統（Society for Worldwide Interbank Financial Telecommunication）**：跨行財務電信協會的系統平台，用於銀行間傳送標準化金融訊息。
- **使用者憑證（User Certificate）/編碼區分**：依用途區分憑證類型，包括伺服器憑證、管理者憑證及使用者憑證。
- **管理者憑證（Administrator）**：可管理 SWIFT Alliance 與 MT（或 MX）Messages 的管理身分憑證，並要求不同管理者憑證由不同人員掌管。
- **Token**：授權/存取所需的憑證載具或通行資源；本準則要求領取、移轉、盤點與登記留存。
- **RMA**：通匯行交換通匯鑰匙執行（與跨行通匯鑰匙交換相關的功能）。
- **Message Function 權限五類**：
  - **Message Creation**：電文製發及暫存  
  - **Message Modification**：電文修改  
  - **Message Approval**：電文放行  
  - **Message Search & Report**：電文與報表查詢  
  - **RMA**：執行通匯行交換通匯鑰匙
