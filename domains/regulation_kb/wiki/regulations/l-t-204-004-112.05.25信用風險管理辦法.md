# 這是什麼

本辦法是公司董事會核定的信用風險管理規範，適用於公司及各子公司，涵蓋信用風險的辨識、衡量、監控，以及發行人與交易對手的額度及信用評等管理。

# 跟我們業務的關聯

固定收益／債券交易部門進行債券投資、店頭衍生性金融商品交易及款券交割時，主要會受到下列規定影響：

- **信用風險分類與管理程序**（第二條、第三條）：
  - 信用風險至少分為**發行人風險**及**交易對手信用風險**；後者包括交割風險與交割前風險。
  - 業務單位應辨識並歸類交易可能產生的信用風險；衡量時須考量信用特徵、產品差異、市場變化及交易參與人或交易對手的信用。
  - 風險管理單位除監控個別發行人及交易對手，也須監控整體信用部位，及早發現問題資產或可能違約的交易。

- **信用風險額度架構**（第四條）：
  - 額度設定須考量公司資本、營運策略、違約機率（PD）、違約損失率（LGD）及違約曝險額（EAD）。
  - 應按**交易對手別、評等別、產品別、行業別、集團別及國家別**設定單獨額度與總合額度。
  - 信用風險額度限額是發行人信用風險額度與交易對手信用風險額度的合計限額，由風險管理單位每年配合公司資本及營運策略訂定並呈董事會核定。
  - 集團別定義與歸戶原則，依金控母公司《集中度管理辦法》的同一關係企業規定辦理。
  - 額度申請、分配及流用機制應另以管理要點規範；交易前仍須依相關額度作業程序辦理。

- **債券發行人額度**（第五條）：
  - 發行人額度以各類債權投資標的的信用評等為基準，並參考EL、PD及LGD等指標核定個別發行人交易額度。
  - 適用標的包括主權債、機構債、超國籍債、公司債、金融債、可轉換公司債、結構型債券、資產擔保債券、CLO、MBS及其他具債權性質的有價證券。
  - 因此，即使不同商品由同一發行人或同一集團發行，仍須同時確認個別發行人額度、集團歸戶額度及相關總合限額。

- **交易對手額度與衍生性商品**（第六條）：
  - 店頭衍生性金融商品的交易對手，應依外部或內部信用評等分級，並以EL、PD及LGD等指標推導個別交易對手信用風險額度上限。
  - 如交易對手自評價基準日至合約終止日均無現金流量支付義務，該交易不計算交易對手信用風險額度。
  - 交易前應確認交易對手已事先審核通過，且交易位於核准市場、核准標的及授權交割額度內。

- **款券交割條件**（第六條）：
  - 交割原則上須符合下列任一方式：
    1. 經保管銀行辦理款券同步交割（DVP）。
    2. 採安全交割，由對方先將款或券轉至我方指定帳戶後，我方再撥付券或款。
    3. 由我方賣出且標的債券同時交由我方保管。
    4. 在初級市場直接向發行公司認購債券。
  - 交割並須於認可期間內完成；不能符合規定時，須在交易前取得授權，不可先成交後補辦。

- **投資等級與信用評等使用原則**（第七條）：
  - 投資債權有價證券或承作OTC衍生性金融商品時，發行人及交易對手原則上應為**投資等級以上**；例外情形須先經被授權的適當層級核准。
  - 有外部評等時優先採外部評等；無外部評等時，才以內部評等作為信用評等。
  - 主順位債券原則上依序採用標的評等、擔保機構評等或發行公司評等；均無法取得時視為無評等。
  - 次順位債券若無標的評等且無擔保，原則上視為無評等；本國金融控股公司及本國金融機構發行的次順位債券，如無標的評等，則以發行機構評等的次一級認定。
  - 金融機構聯合擔保的有擔保債券若無標的評等，以各擔保機構中最低評等為準。
  - 風險管理單位每季檢視信用評等變動；不同評等機構的評級不一致時，以最新發布者為準，如同時發布則採最低評等。

- **額度預警及超限處理**（第八條）：
  - 風險管理單位須**每日**監控發行人額度及交易對手額度。
  - 限額使用率達**80%預警值**時，應通報相關交易單位主管。
  - 發行人額度或交易對手額度超限且無法即時補正時，須通報相關交易單位、稽核單位及總經理，並依辦法所定超限處理程序辦理。

- **大額曝險與利害關係人交易**（第九條）：
  - 對同一人、同一關係人或同一關係企業的信用風險總額，不得超過公司內部或主管機關規定的上限。
  - 超限時須立即處理、呈報總經理，並通知公司及金控的風險管理單位。
  - 與主管機關定義的利害關係人及其關係企業進行授信或授信以外交易時，另須遵守相關法令及內部規定。

- **大陸地區曝險**（第十條）：
  - 大陸地區曝險須同時符合董事會核准的國家別限額，以及金控整體對大陸地區的曝險限額。
  - 公司每月須提供可供稽核查對的曝險明細與統計資料，由金控風險管理單位彙整並向金控董事會報告。

- **承銷部位控管**（第十一條）：
  - 若業務涉及承銷或包銷，包銷或有部位須依承銷相關辦法及分層負責核決權限事先取得授權，並在承銷期間內納入信用風險額度控管。

# 關鍵定義

- **信用風險**：發行人、契約交易相對人或債務人未履行責任，或其信用品質改變而造成損失的風險（第二條）。

- **發行人風險**：發行人、債務人或保證人因破產、違法，或稅法、會計原則改變等因素導致信用惡化，無法還款或遵守發行條款的風險（第二條）。

- **交易對手信用風險**：從事金融交易時，交易對手、保管行、經紀商等交易參與人未依合約履行責任或義務的風險（第二條）。

- **交割風險（Settlement Risk）**：交割過程中，一方已交付款項或證券，另一方卻未依約完成對應給付的風險。

- **交割前風險（PSR，Pre-settlement Risk）**：交易成立後至完成交割或合約終止前，因交易對手違約而可能產生損失的風險。

- **預期損失（EL）**：依違約機率、違約損失率及違約曝險額估算，在正常情況下預期可能發生的信用損失。

- **違約機率（PD）**：發行人或交易對手在一定期間內發生違約的可能性。

- **違約損失率（LGD）**：發生違約後，扣除可回收金額後的損失比例。

- **違約曝險額（EAD）**：發生違約時，預計暴露於該發行人或交易對手的金額；辦法以EL、PD及LGD等指標推導信用風險額度上限。

- **轉換乘數（k）**：依巴塞爾風險資本與違約機率關係推導、用於額度衡量的參數，由風險管理處決定。

- **投資等級**：穆迪（Moody's）Baa3、標準普爾（S&P）BBB-以上（含），或其他主管機關認可信用評等機構評定的相當等級（第七條）。

- **外部信用評等**：中華信用評等公司，或經金融監督管理委員會核准或認可的信用評等機構所評定的信用等級（第七條）。

- **內部信用評等**：公司及子公司自行建立、並與金控內部信用評等適當轉換的評等制度。等級分為1至9及D；1代表信用品質最佳，D代表違約，1至4為低度風險、5至6為中度風險、7至9為高度風險，原則上1至6為可投資等級（第七條）。

- **款券同步交割（DVP）**：證券移轉與款項支付相互連動，以降低一方已付款或交券、另一方卻未履約的交割風險。
